## M4 功能证据

- Dashboard 与日志只在页面可见且代理开启时创建 Clash API WebSocket；离开、停止、重载会取消，未使用 Timer 或 REST 轮询。
- 流量曲线固定 60 点；实时日志固定 2000 行；普通/TUN 磁盘日志单文件 5 MiB，保留当前文件和一份归档。
- 默认国内 DoH 为 `223.5.5.5` 直连，远程 DoH 为 `8.8.8.8` 经“自动选择”；域名 DoH 使用有限 direct bootstrap，TUN 添加 DNS hijack，默认无 fake-ip。
- 自动订阅默认 24 小时、范围 1–168 小时；只安排一次可取消 sleep，唤醒后重排。失败或缓存兜底保留旧节点/成功时间并尝试通知。
- `SMAppService.mainApp` 初始化只读实际状态；只有用户开关调用注册/注销，requiresApproval 不循环注册。
- 普通/TUN 以 `DispatchSourceProcess(.exit)` 监听精确 PID；主动 stop、模式切换、DNS/规则/TUN 重载先取消监控，成功或回滚后绑定新 PID。
- 真实普通用户 sing-box 被 SIGKILL 后以新 PID 恢复，未重复调用 networksetup；TUN 崩溃和第 4 次终止使用 fake launcher/monitor 验证。
- XCTest 非 `.app` 宿主硬拒绝真实通知中心；所有 networksetup、TUN、登录项、通知测试均使用 recorder/fake。
