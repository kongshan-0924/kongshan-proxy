# kongshan 网络可观测与控制增强设计

## 目标

在保留 0.1.22 侧边栏修复的基础上，为 kongshan 增加用户可直接验收的网络状态、节点识别、连接速率、自动选最快、分应用规则、托盘速率和备份恢复能力。所有改动留在 `codex/network-observability-batch`，用户验收前不合并 main。

## 范围与取舍

1. “出口连通性卡”和“出口 IP 卡”是同一需求，只实现一个“出口诊断”卡，显示真实出口 IP、城市/国家、网络组织并可刷新。
2. “DNS 泄漏”不是简单比较 DNS IP 与出口 IP。自测通过 Mullvad 的唯一 DNS 域名观察递归解析器，再结合当前出口和配置的远程 DoH 提供三态结论：未发现明显泄漏、可能泄漏、无法判断；详情列出解析器。
3. 节点元数据只影响展示，不重命名或修改订阅节点。优先使用名称内旗帜，其次用常见地区关键词推断；倍率识别 `3x`、`3×`、`3倍`、`倍率 3`。
4. 连接实时速率由同一连接相邻 WebSocket 快照的累计字节差除以时间得出。连接首次出现、计数回退或断流时速率为 0，不制造负数或尖峰。
5. “测速并自动选最快”只在当前可手动选择的策略组内选择测速成功且延迟最低的节点；测速全失败则保留原选择并提示。
6. 分应用代理复用 `CustomRouteRule(processName)`。App 来源使用当前运行的普通 macOS 应用，保存的是可执行文件名。目标支持直连、默认代理、指定节点；指定节点直接引用稳定的 `node-UUID` 出站 tag。
7. 菜单栏图标旁显示紧凑的上下行速率，下拉菜单显示完整速率。仪表盘和托盘通过消费者集合共享唯一流量 WebSocket，避免页面切换互相取消订阅。
8. 备份是版本化 JSON，包含订阅源、手动节点、通用设置和路由设置，不包含日志、缓存、运行时密钥或恢复文件。导入先完整解码与校验，再替换并持久化；运行中导入被禁止，避免半应用状态。

## 数据结构

- `ExitIPInfo`：IP、城市、国家、组织、采样时间。
- `DNSResolverInfo`：IP、城市、国家、组织、是否 Mullvad DNS。
- `DNSLeakAssessment`：`clear`、`possible`、`indeterminate` 与说明。
- `ExitDiagnosticsService`：注入 `URLSession`，请求 `/config`、`/json` 和 3 个唯一 DNS 域名；并发、有超时、去重。
- `NodeNameMetadata`：纯函数解析旗帜、地区、倍率。
- `ConnectionRateTracker`：按连接 ID 保存上一快照与时间，输出每秒上下行。
- `ConnectionLiveDetail`：连接详情与两项实时速率。
- `KongshanBackup`：版本、创建时间、四类持久化数据。

## 界面

- 仪表盘第三张卡改为“出口 IP”，主值是 IP，副值是 `旗帜 城市, 国家 · 运营商`；刷新按钮触发完整出口诊断。下方新增 DNS 状态与“检测”入口。
- 代理页节点卡在名称旁展示地区旗帜，底部突出倍率 badge；工具栏增加“测速并自动选最快”。
- 连接页顶部展示总上传/下载速率，并提供默认、总速率、上传、下载排序；每行同时显示实时速率与累计流量。
- 规则页顶部加入“分应用代理”区域：运行中 App Picker、路由目标、添加按钮，下面列出并可删除现有 process_name 规则。
- 设置 → 更多加入备份导出和导入。

## 错误与隐私

- 出口/DNS 服务错误保留上次成功结果并显示刷新错误；首次失败显示无法获取。
- DNS 结论是启发式网络自测，文案明确“未发现明显泄漏”而不是绝对安全承诺。
- 导出备份前提示订阅链接可能含凭据；文件由用户选择位置。
- 不记录外部 IP 或 DNS 解析器到项目日志、应用日志或备份。

## 验收标准

- 代理开启、关闭、系统代理、TUN 四种状态均不崩溃；出口诊断可刷新并显示真实结果或明确错误。
- 节点名称示例 `🇯🇵 3x JP` 显示日本旗帜与高亮 `3×`，搜索/排序不退化。
- 同一连接第二个快照显示正确 B/s，顶部速率和排序同步。
- 自动测速成功选中最低延迟节点，全失败不切换。
- 可从运行中 App 添加直连/默认代理/指定节点规则，生成配置通过 sing-box check。
- 仪表盘开关不影响托盘速率，只有一条全局流量订阅。
- 导出后可导入恢复，损坏/不支持版本文件不修改当前数据。
- `swift test`、发布验证脚本、签名和 DMG 校验全部通过；只交付一个安装 App 与一个 DMG。
