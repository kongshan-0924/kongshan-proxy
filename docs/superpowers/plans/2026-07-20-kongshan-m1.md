# kongshan M1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付可双击运行的 `kongshan.app`，完成订阅导入、手动 Hysteria2、配置校验、sing-box 进程、系统代理、Clash API 节点选择/测速和菜单栏开关。

**Architecture:** SwiftPM 只包含 `KongshanCore`、`kongshan` 和 `KongshanCoreTests`。纯转换与配置生成放在 Core；有副作用的存储、进程、HTTP 和系统代理各自集中在一个文件；`@MainActor AppState` 串联原生 SwiftUI 界面。

**Tech Stack:** Swift 6 严格并发、SwiftUI、Observation、Foundation、Security、Yams 6.2.2、XCTest、sing-box 1.13.14 darwin-arm64。

- [ ] **Step 3: 用 Yams.load 实现容错转换**

```swift
public struct ConversionResult: Sendable {
    public let nodes: [ProxyNode]
    public let warnings: [String]
}

public enum ClashSubscriptionConverter {
    public static func convert(yaml: String, sourceID: UUID) throws -> ConversionResult {
        guard let root = try Yams.load(yaml: yaml) as? [String: Any],
              let proxies = root["proxies"] as? [[String: Any]] else {
            throw SubscriptionError.missingProxies
        }
        var nodes: [ProxyNode] = []
        var warnings: [String] = []
        for raw in proxies {
            do { nodes.append(try map(raw, sourceID: sourceID)) }
            catch { warnings.append("\(raw["name"] ?? "未命名"): \(error)") }
        }
        guard !nodes.isEmpty else { throw SubscriptionError.noSupportedNodes(warnings) }
        return ConversionResult(nodes: nodes, warnings: warnings)
    }
}
```

`map` 对每种类型明确读取必填字段；未知类型和单节点字段错误仅写 warning。`network: ws/grpc`、`ws-opts.path/headers`、`grpc-opts.grpc-service-name` 映射到 `TransportOptions`。

public struct RuntimeParameters: Sendable {
    public let mixedPort: UInt16
    public let clashPort: UInt16

public enum RuntimeSecrets {
    public static func secret(byteCount: Int = 32) throws -> String {
        var bytes = [UInt8](repeating: 0, count: byteCount)
        guard SecRandomCopyBytes(kSecRandomDefault, bytes.count, &bytes) == errSecSuccess else {
            throw RuntimeError.randomGenerationFailed
        }
        return Data(bytes).base64EncodedString()

}
