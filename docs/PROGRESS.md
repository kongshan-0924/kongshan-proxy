## 已实现的能力

**代理与分流**

- [x] Clash YAML 订阅导入、自动更新、用量/到期、配置切换与缓存兜底
- [x] SS（含 SIP003 插件）/ Trojan / VMess / VLESS（Reality·uTLS·Vision）/ Hysteria2 / AnyTLS
- [x] 分享链接粘贴解析（上述六种协议，可批量，坏行跳过）
- [x] 机场策略组、订阅规则、自定义规则、分应用代理、直连/规则/全局
- [x] 系统代理与 TUN 可独立/同时开启；gVisor + Fake-IP 固定；IPv4/IPv6 适配
- [x] 内网 DNS 分流（DHCP 搜索域 → 没有则用内网 DNS 的 PTR 推断 AD 域）

**稳定性**

- [x] 单实例保护（避免两个实例互相写坏系统代理快照）
- [x] 本地 mixed 端口跨启动固定（含被占用时的退避重试）
- [x] 节点域名解析走无连接 UDP（DoH 长连接被 NAT 回收会让整个代理停摆）
- [x] 免密码 TUN helper：签名/cdhash 钉死、配置白名单、孤儿内核认领、单线程无并发
- [x] 系统代理/DNS 快照、失败回滚、启动恢复、换网补挂、睡眠唤醒重建隧道
- [x] 崩溃自愈 + 限流，达到上限时还原系统代理
- [x] 物理网络只有 ULA/链路本地 IPv6 时，TUN 自动移除 IPv6 地址，避免应用新连接走入无默认路由
- [x] 未生效订阅/节点变化不重启当前内核；只有当前运行配置真正变化才走校验、重载与回滚
- [x] 真实换网时用 SystemConfiguration + 物理接口 DHCP 重探 LAN DNS，并重建内核刷新 DoH 传输

**界面**

- [x] 空山图标（App + 菜单栏三种样式可切换）
- [x] 菜单栏原生 `NSStatusItem + NSMenu` 显示整机实时速度；速度刷新与持久化菜单解耦
- [x] 仪表盘本次会话累计流量（跨内核重启连续）
- [x] 规则按目标策略分组折叠
- [x] 内核日志「只看问题」「按连接聚合」，搜索匹配目标主机
- [x] 预期 `block[reject]` 不再算问题；换网根因同一 30 秒桶聚成“网络切换期间”
- [x] 连接页累计合计、链路显示节点名
