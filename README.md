# kongshan 空山

一款面向 Apple Silicon Mac 的原生、轻量 sing-box 图形客户端。

空山使用 SwiftUI + AppKit 构建，内置官方 sing-box 1.13.21，不自行实现代理协议或加密算法。它以“配置”为中心，支持系统代理与 TUN 单独或同时运行，重点解决日常使用中最实际的几个问题：切换要快、菜单要稳、资源要轻、退出后网络必须恢复。

[下载最新版本](https://github.com/kongshan-0924/kongshan-proxy/releases/latest) · [版本历史](CHANGELOG.md)

## 主要功能

| 功能 | 说明 |
|---|---|
| 配置管理 | 导入 Clash YAML 订阅，一个订阅对应一个配置；快速切换、缓存和定时更新；切回某个配置时恢复它上次选的节点 |
| 节点支持 | Shadowsocks、Trojan、VMess、VLESS、Hysteria2、AnyTLS |
| 代理模式 | 系统代理、TUN，可单独开启或同时开启；支持规则、全局、直连出站模式 |
| 策略组 | 沿用订阅中的策略组，支持节点切换、批量测速、取消测速和自动选择最快节点 |
| 订阅规则 | 识别订阅自带的 `RULE-SET`（rule-providers）、`GEOIP,CN` 与 `MATCH`，规则集后台下载、转换并定期刷新 |
| 自定义规则 | 强制代理域名、IP、CIDR；自定义绕过；按应用进程分流；内网网段排除；指定 SSH 目标走代理 |
| 局域网共享 | 让同一局域网的手机、电脑使用本机的分流规则与节点，只接受私网来源，可查看已接入设备与用量 |
| 运行监控 | 实时速度、会话流量、活跃连接、出口 IP、内核内存和运行时长；运行指标按分钟持续记录 |
| 出口与诊断 | 出口 IP 与位置、IP 风险评分、AI 与基准站点可达性自测、DNS 泄漏检测、规则命中测试、网络自检与修复 |
| 连接与日志 | 查看目标、进程、命中规则和完整出站链路；警告、运行事件与内核日志在同一条时间线上筛选和搜索 |
| 菜单栏 | 显示代理状态和整机上下行速度，可直接切换模式、策略和节点 |
| 恢复与自愈 | 系统代理 / DNS 自动恢复、系统代理残留实时清理、崩溃自愈、换网与睡眠唤醒恢复、开机后恢复上次的接管模式、脱敏诊断导出 |

## 安装

**一键安装或升级**（下载最新 Release，校验 SHA-256、签名、版本与架构后替换）：

```bash
curl -fsSL https://raw.githubusercontent.com/kongshan-0924/kongshan-proxy/main/scripts/install_latest.sh | zsh
```

脚本只请求旧版正常退出，确认系统代理、DNS 与 TUN 都已还原、直连可用后才替换；替换前会备份配置，旧版移入废纸篓，可随时拖回。已是最新版时不做任何事。可选参数：`--check` 只下载并校验、不动已安装的 App；`--force` 已是最新也重装。管道方式运行时写成 `… | zsh -s -- --check`。

**手动安装**：从 [Releases](https://github.com/kongshan-0924/kongshan-proxy/releases) 下载最新 DMG，打开后把 `kongshan.app` 拖入“应用程序”。

当前发布包使用 ad-hoc 签名，没有 Apple Developer ID，也未公证。首次启动请在“应用程序”中右键 `kongshan.app`，选择“打开”。

## 使用步骤

### 1. 导入配置

打开“配置”页面，粘贴 Clash YAML 订阅链接并导入。也可以：

- 批量粘贴 `ss`、`trojan`、`vmess`、`vless`、`hysteria2`、`hy2` 或 `anytls` 节点链接；
- 手动添加 Hysteria2 节点；
- 在多个本地配置之间快速切换，每个配置记住自己上次选的节点。

订阅里引用的规则集会在后台下载，下载完成前用空规则集占位，不影响启动；下载好后内核自动热加载，不必重启。

订阅内容和本地设置默认保存在：

```text
~/Library/Application Support/kongshan/
```

### 2. 选择节点

进入“代理”页面，在订阅策略组中选择节点。可以先运行“测速全部”，也可以直接“测速并选最快”（菜单栏里同样可用）。测速方式有两种：TCP 握手直连节点服务器，快且稳；URL 测速经代理请求测试地址，测的是真实链路但更慢。测速任务支持进度显示和取消，失败时会说明原因。

### 3. 开启代理

在仪表盘或菜单栏开启：

- **系统代理**：适合浏览器和遵循 macOS 代理设置的应用，开启快、开销低。只转发 TCP。
- **TUN**：接管所有应用的流量，包括不读取系统代理的命令行工具和 UDP（如 QUIC），并提供完整 DNS 分流；按应用进程分流只对经 TUN 接管的流量生效。
- 两者可以同时开启，系统代理入口保持不变。同时开启时，浏览器等遵循系统代理的应用仍然走系统代理入口，内核认不出它们是谁（连接页显示为「经系统代理」），按应用进程分流管不到它们；要按 App 分流，请只开 TUN。

### 4. 可选：安装免密码助手

第一次使用 TUN 会需要管理员授权。可以在“设置 → 接管”安装免密码助手，授权一次后，日常启停 TUN 不再重复弹出密码框。

App 更新后签名指纹可能变化，界面提示“需重装”时重新安装一次即可。助手的签名和路径校验不能绕过。

### 5. 可选：局域网共享

在“连接”页开启局域网共享。同一网段的设备把 HTTP 或 SOCKS5 代理填成页面上显示的地址与端口即可，例如 `192.168.1.10:7890`；同一个端口同时支持两种协议。

- 端口固定使用设置里的值（1024–49151）。被占用时会明确报错，不会悄悄换端口，以免其他设备失联。
- 来源白名单留空表示允许全部私网地址，填了则只允许列出的网段；公网来源一律拒绝。
- 连接页会列出已接入的设备和各自用量。连不上时，页面上有四项排查：是否同网段、路由器 AP 隔离、本地网络权限、防火墙。

### 6. 正常关闭

从菜单栏退出空山即可。程序会先停止内核，再恢复系统代理和 DNS；如果上次异常结束，下次启动也会优先尝试恢复遗留设置。

如果在“设置 → 通用”开启了开机自启并勾选“登录后自动恢复上次的接管”，登录后会等网络就绪，再恢复到关机前的模式。恢复 TUN 需要已装免密码助手；没装时会跳过这一组并通知原因，避免登录时凭空弹出密码框。

## 特色功能

### 稳定的系统代理入口

系统代理始终连接由 App 持有的本地 TCP relay。普通模式和 root TUN 内核使用各自独立的内部端口，切换模式时只更换 relay 后端，不再让不同权限的 sing-box 争抢同一个监听端口。

这样可以避免模式切换时端口漂移、浏览器反复重连，以及系统代理暂时指向失效端口造成的断网。

### 有实时速度、但不会闪烁的原生菜单

菜单栏使用 AppKit 原生 `NSStatusItem + NSMenu`。整机速度每两秒更新，但不会重建正在展开的菜单，因此节点子菜单可以稳定停留和选择，“打开仪表盘”也不会因周期刷新失效。

速度读取物理 `en*` 网卡，不重复统计 TUN 流量，代理关闭时也能继续显示整机网速。

### 为轻量和流畅做过专门优化

- 仪表盘指标合并发布，曲线降低刷新频率；窗口不可见时停止无意义的图表更新；
- Clash API 使用推流而不是高频轮询，页面离开后及时释放非必要任务；
- 日志批量更新并限制数量，避免高频日志反复重绘界面；
- 批量测速采用有界并发、分批更新和可取消任务；
- 配置、规则和节点切换尽量热更新，必须重启内核时提供失败回滚；
- 断网等建连失败密集时，日志文件里的逐条连接记录自动折叠成每分钟一条汇总，不会刷屏冲掉之前的记录；告警检测照常看到每一行。

### 订阅自带的规则集

很多订阅的分流规则几乎全是 `RULE-SET`，规则内容放在 rule-providers 里。空山会按订阅顺序把它们接进路由与 DNS：

- 支持 `http` 类型、`classical` / `domain` / `ipcidr` 行为、`yaml` / `text` 格式；`mrs`、`file`、`inline` 暂不支持，会跳过并提示；
- `GEOIP,CN` 使用内置的中国 IP 规则集，其他国家码跳过；`MATCH` 作为兜底出口，对应“漏网之鱼”分组；
- `GEOIP,CN` 只按连接本身的 IP 判定，不为它去解析域名（相当于一律 `no-resolve`）。Clash 会先用国内解析器把域名解析成 IP 再比对，但被墙域名在国内解析器上拿到的污染地址可能恰好落在国内段，会被误判直连而打不开；
- 没进订阅名单的国内站由内置的**国内域名扩展名单**兜底直连：v2fly 的 cn 与 dnsmasq-china-list（权威 DNS 在国内的域名）合并而成，约 11 万个域名，来自 MetaCubeX/meta-rules-dat，与其他规则集一起每天更新。它排在订阅规则之后、`MATCH` 之前，订阅明确送去代理的域名不受影响；下载不到时不用，不影响启动；
- 刷新周期沿用订阅里的 `interval`（最短 1 小时，缺省 1 天）；下载失败时沿用上次的缓存；
- 生成配置时不联网，没下载好的规则集先用空规则集占位；
- 规则页显示每个规则集的条数与下载状态，诊断页的命中测试按已下载的内容判定。

### 强制代理与规则诊断

可以把指定域名、单个 IP 或 CIDR 强制交给某个代理策略，也可以按应用进程分流（只对经 TUN 接管的流量生效，见上文“开启代理”）。诊断页可以测试某个域名、IP 或进程会命中哪条规则；连接页可以直接查看某条连接命中了什么规则、经过哪些策略和节点。

这类规则优先于订阅分流和中国大陆直连规则，适合处理下载站、数据库、企业服务或特定客户端没有按预期走代理的问题。

还可以指定某些 SSH 目标走代理。空山只维护自己托管的 `~/.ssh/kongshan-proxy.conf`，并在 `~/.ssh/config` 里加一行 `Include`；不会读取或保存 SSH 密码、私钥，也不会改动你已有的 Host 配置。

### 出口分析与网络自检

诊断页把排查需要的东西放在一起：

- **出口 IP**：地址、位置与归属，以及 IP 风险评分与类型标签；
- **站点可达性自测**：直接请求 ChatGPT、Claude，以及 Google、Cloudflare 两个基准站。“需人机验证”单独成一类——那是出口 IP 信誉问题，换网段有用；基准站也不通才是节点问题；
- **DNS 泄漏**：结论，以及实际使用的解析器明细；
- **网络自检与修复**：检查接管残留、网络服务设置、残留内核进程与连通性，发现问题就地修复；
- 检测结果可以一键复制成纯文本报告，反馈问题时比截图有用。

### 面向真实网络环境的 TUN

- 固定使用 gVisor 用户态网络栈；
- 使用 Fake-IP，并持久化映射；`.invalid`、`.test`、`.example`、`.localhost`、`.onion` 这类保留名直接回“不存在”，`.local` / `home.arpa` 交给本地解析器，不带点的局域网设备名（如 NAS）交给内网 DNS 或回“不存在”让系统改用局域网发现，都不发假 IP；
- 系统 DNS 指向 TUN 接口自身地址；
- 启动前探测局域网 DNS，避免企业内网域名被错误送往代理节点；
- 换 Wi-Fi、切热点或睡眠唤醒后，重新检查网络身份、LAN DNS、DoH 连接和 TUN 接口；
- 合盖睡眠期间系统每隔一阵会短暂“暗唤醒”，那几秒网络还没恢复、后台请求集中失败。醒来后 90 秒内的失败不计入告警，醒来后网络真坏了照样会报。

### 安全、可恢复的特权助手

免密码助手只负责启动和停止内置 sing-box，不接受任意命令或路径。它会校验 App 身份、bundle 路径、签名指纹、内核指纹和配置白名单；配置通过只读文件描述符传递，不写入命令行。

系统代理和 DNS 在接管前都会保存原始快照。启动失败、配置重载失败、内核崩溃或正常退出时，会按状态回滚，避免留下指向失效端口的系统设置。暂时不在的网络服务（拔掉的网卡、未运行的 VPN）会保留快照，等它回来再还原。没在接管时，一旦发现有网络服务的代理被改回指向空山的端口（比如重启后被还原），几秒内自动清掉。

## 系统要求与限制

- Apple Silicon Mac（arm64）
- macOS 14 或更高版本
- 当前发布包为 ad-hoc 签名，首次打开和 App 更新后的助手授权受 macOS 安全策略影响
- 订阅只支持 Clash YAML 格式
- TUN 固定使用 gVisor + Fake-IP；同时运行多个 TUN/VPN 客户端可能互相争抢路由
- 系统代理只转发 TCP，且只影响遵循 macOS 代理设置的应用；UDP（如 QUIC）、不读取系统代理的程序，以及按应用进程分流，都需要开启 TUN；两者同开时，遵循系统代理的应用不受按进程规则约束
- 项目不提供代理节点，请使用自己的合法订阅或自建节点

## 数据与隐私

- 订阅、规则、设置、节点和日志保存在本机 Application Support 目录；应用没有账号系统，也没有云同步。内核日志在其中的 `logs/`：只开系统代理时是 `sing-box.log`，开着 TUN 时是 `sing-box-tun-stream.log`（均为 5 MB 滚动；更早的旧档压缩成 `.gz` 留在同一目录，每种保留 48 小时、合计不超过 64 MB）。
- Clash API 端口与 secret 只保存在内存。
- 数据目录里的 `config.json` 是去除凭据后的诊断快照。

**应用自己会发起的网络请求**：

| 用途 | 地址 | 时机 |
|---|---|---|
| 节点测速 | 经各节点访问 `www.gstatic.com/generate_204` | 测速时 |
| 出口 IP、位置与 DNS 泄漏 | `am.i.mullvad.net` | 代理开启时自动检测，也可手动刷新 |
| IP 风险评分 | `my.ippure.com`（会把当前出口 IP 发给该服务） | 随出口检测一起进行 |
| 站点可达性自测 | `chatgpt.com`、`claude.ai`、`www.google.com`、`www.cloudflare.com` | 在诊断页点“开始检测”时 |
| 内置规则集 | `raw.githubusercontent.com`、`fastly.jsdelivr.net`（SagerNet 规则集） | 按需下载与刷新 |
| 订阅与订阅规则集 | 订阅里写的地址 | 导入、定时更新时 |
| 检查内核新版本 | `api.github.com` | 在“设置 → 通用 → 关于”手动点击时 |
| DNS | 默认国内 DoH `223.5.5.5`、境外 DoH `8.8.8.8`（经代理） | 解析域名时，可在“设置 → 网络”修改 |

**诊断导出**分两版，都不读取订阅文件、备份和节点缓存，都会去掉密码、UUID、密钥、令牌、Reality 公钥与 short_id 等凭据字段，本机用户目录替换成 `~`：

- **完整版**（自用排查）**仍包含**节点服务器地址与端口、SNI、自定义规则与绕过列表、内网 DNS 地址、告警原文里的地址，以及内核日志里访问过的目标域名，只发给信任的人；
- **可公开分享版**再去掉内核日志，节点地址 / SNI / 伪装域名换成代号，规则里的域名、IP、进程与端口和 DNS 服务器地址隐去，告警与事件里的 IP、链接和节点名换成编号；保留规则顺序与出站去向，排查仍看得懂。

## 本地构建

需要 Xcode Command Line Tools 和 Swift 6 工具链。

```bash
zsh scripts/build_app.sh       # 构建 .build/kongshan.app
zsh scripts/make_dmg.sh        # 生成 dist/kongshan-<版本>.dmg
zsh scripts/verify_m4.sh       # 完整测试、签名、资源与空闲 CPU 门禁
zsh scripts/release.sh prepare # 生成与当前 Git 提交绑定的发布候选
```

构建 App 位于 `.build`，`dist` 只保留最新 DMG。正式使用时请只运行 `/Applications/kongshan.app`，避免同时启动多个副本。
